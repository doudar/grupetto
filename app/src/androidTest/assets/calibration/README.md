# Legacy calibration fixtures

These are synthetic observations serialized by authentic historical production code, not data from a user's bike or evidence of a device upgrade test.

- `released-v0.0.49-v0.0.50-smoothed.json`: generated independently with the unchanged production calibration sources from release tags `v0.0.49` (`5061774aee3eaf6540bf8f9aedf448e2c7cd81d5`, build 51) and `v0.0.50` (`7a543d18629e41c9ccc5758f185a4ce7da4931b9`, build 52). Both encoders produced byte-identical JSON before whitespace compaction.
- `pre-combined-draft.json` and `pre-combined-active.json`: generated by the production separate-file store at `11b8c21a620e78493798b7f0a7c22605a75d5a2f`, the parent of the combined-backup introduction `e045bd5`.

All fixture generators used this exact capture setup:

```kotlin
val baseline = List(31) { 1000 + it * 100 }
val samples = (8..16 step 2).flatMap { x -> listOf(65, 80, 95).map { rpm ->
    val watts = 80.0 + x * 8
    CalibrationSample(baseline[x].toDouble(), rpm.toDouble(), watts,
        watts * (1.1 + (rpm - 80) / 1000.0), (x * 100 + rpm).toLong())
} }
val capture = CalibrationCapture("release-upgrade-bike", "release-upgrade-meter", 2040490L, baseline, samples)
val recorded = GrupettoCalibrationProfile(capture, GrupettoCalibrationFitter.fit(baseline, samples))
val sparse = GrupettoCalibrationProfile(capture.copy(samples = samples.take(1)),
    GrupettoCalibrationFitter.fit(baseline, samples.take(1)))
```

Exact released serializer invocation:

```kotlin
var edited = CalibrationManualEdit.setPercent(recorded.table!!, setOf(167), -15.0, true)
repeat(7) { edited = CalibrationManualEdit.smooth(edited, (0 until 496).toSet()) }
val manual = recorded.copy(table = edited)
val json = CalibrationBackup(manual, manual).encode()
```

Exact pre-combined serializer invocations:

```kotlin
GrupettoCalibrationStore(directory, "grupetto-power-draft.json").save(sparse)
GrupettoCalibrationStore(directory, "grupetto-power-active.json").save(recorded)
```

Generation used Kotlin/JVM and Android's `org.json` implementation (`com.vaadin.external.google:android-json:0.0.20131108.vaadin1`). Historical sources came from `git show <revision>:app/src/main/java/com/spop/poverlay/calibration/<file>`. Only Compose color helpers were omitted; the numerical coverage helpers were unchanged. A filesystem shim replaced Android `AtomicFile` solely to write fixture bytes. This does not test Android's atomic-write or process-death behavior. Stored fixtures have whitespace compacted without changing JSON values.
